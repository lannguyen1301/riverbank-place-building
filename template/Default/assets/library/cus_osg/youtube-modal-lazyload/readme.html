Hướng dẫn sử dụng youtube-modal-lazyload by Long Orion

1. Chèn mã sau vào vị trí bạn muốn hiển thị video Youtube trong file template của bạn. Với video có ID là VIDEO_ID, bạn thay thế bằng ID video của bạn. Ví dụ: https://www.youtube.com/watch?v=VIDEO_ID thì bạn chỉ cần lấy phần VIDEO_ID.

2. Đoạn Modal và gọi JS, CSS vào cuối file template của bạn. Bạn có thể thay đổi kích thước của iframe trong CSS nếu cần thiết.
